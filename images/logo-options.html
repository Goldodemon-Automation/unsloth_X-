Pick a mark

Four constructions of the same idea: X in the fork's blue, – in a lighter blue. Each one works on light and dark. Pick by where the mark has to live, not by which preview looks best at 200px.

1. Horizontal, two inks

The default. Best for README headers, splash screens and anywhere the mark has room. The gradient on the X keeps it from reading flat at large sizes; the dash stays one solid light blue so the two halves never look like the same object.

logo-x-minus.svg

2. App icon

For favicons, the desktop icon, store listings and social avatars. A dark plate carries the mark so it survives a light browser tab and a dark dock without a second file.

logo-x-minus-badge.svg

3. Stacked

The tight square: X above the dash. This is the one that still reads at 16px, because the two halves stay legible when they are stacked rather than side by side. Use it for the tab icon inside the app if the badge feels too heavy.

logo-x-minus-stacked.svg

4. One ink

currentColor, with the dash held apart by opacity instead of a second colour. For anywhere only one ink is available: single-colour print, a badge, an engraved plate, an inline icon inside the app. It has to be inlined to inherit the theme — an SVG loaded through <img> cannot see the page's colour and paints black.
